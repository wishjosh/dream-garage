## 코너 주행 비교 시안

[스마트폰에서 비교하기](https://wishjosh.github.io/dream-garage/handling-study.html?v=handling-4)

2026-10-22 사용자 요청으로 만든 별도 도시 코너 시안입니다. 같은 Tavaculo 실내·왼쪽 90도 코너에서 **좌우 버튼 / 엄지 슬라이드**를 선택하고 출발 속도 40·60·100 km/h를 비교합니다. 방식 변경과 ↻는 같은 출발 위치·방향·속도로 복원합니다. 왼손은 조향, 오른손은 가속·브레이크·후진이며 A/D·방향키·W·Space·X도 지원합니다. 슬라이드는 손가락을 놓은 위치에서 중간 조향각을 유지하고, 손을 떼면 정면으로 풀립니다. 주행 중 P/Esc 또는 Ⅱ로 멈출 수 있습니다. 지도에서 이번 주행은 민트, 같은 출발 속도의 다른 조작 기록은 주황으로 표시합니다.

두 조작은 하나의 고정 간격(120 Hz) 평면 2축 타이어 모델을 공유합니다. 앞뒤 타이어의 횡방향 접지 한계, 가속·제동의 종방향 힘과 같은 접지를 나눠 쓰는 제한, 앞뒤 하중 이동, 연속적인 접지 상실·회복을 계산합니다. 고속에서 같은 조향각을 줬을 때의 넓어지는 궤적과 강한 후륜 가속에서의 뒤 미끄러짐이 실제 위치·횡속도·회전으로 나타납니다. 상태 표시와 타이어 자국은 계산된 미끄러짐을 따릅니다. 도로 자동 조향이나 드리프트 버튼에 의한 회전 도움은 없습니다. 실차 측정으로 보정한 타이어 모델이나 본 게임의 3D 서스펜션 교체본은 아닙니다. 본 경주 물리·상금·꾸미기·저장은 유지하며 시안 자체는 저장소에 접근하지 않습니다.

Gallardo 원본 비례·고정 눈 위치와 기존 실시간 후방 영상을 재사용합니다. 가로·세로에서 실내 부품을 개별 변형하지 않으며, 세로 후방 표시는 조작 방식 선택 영역 아래에 배치합니다. 반복 도시 구조물은 묶어서 그리고 픽셀 비율은 최대 1.5로 제한합니다.

**검증:** 전체 자동 검사 105개(기존 86 + 주행·입력 19), JavaScript 문법 35개 파일, 두 조작 × 6개 화면(844×390·740×360·390×844·360×740·320×568·568×320)의 12개 브라우저 조합이 통과했습니다. 같은 조향각의 저속/고속 궤적, 가속 시 뒤 미끄러짐, 가속 해제·감속 뒤 반대 조향의 자동 조절 없이 회복, 충돌·제동·후진, 프레임 간 일관성과 저장 비접근을 확인합니다. 브라우저 하네스는 두 손가락 합성 입력·취소·해제·중간 각도 유지·미세 조정·방식 전환·일시정지·창 전환·화면 회전·시점 전환·원본 109개 객체의 비례를 검사하며 실행 오류는 없었습니다. 일반 브라우저에서 실제 포인터 길게 누르기와 드래그도 확인했습니다. 실제 iPhone·Android 멀티터치 하드웨어·장시간 성능·운전 재미는 사용자 검토 전입니다.

**제동 중 반대 조향 수정 — 2026-10-22:** 앞 타이어에 제동 접지를 먼저 배정해 조향력이 사라지고 반대 방향 제동 성분만 남던 오류를 수정했습니다. 앞 타이어의 종·횡 방향 요구를 함께 연속 포화시켜 제동과 조향이 접지를 나눠 씁니다. 정지 부근에서도 두 성분을 함께 줄여 방향이 뒤집히지 않게 했습니다. 10·40·60·100 km/h의 좌우·약/강 제동·작은/큰 조향과 코너 진입 뒤 제동·정지까지 핸들 유지 회귀 검사를 추가했습니다. 브라우저에서 두 조작 × 가로/세로 × 40/60/100 km/h × 좌우의 동시 제동 24개 조합을 통과했습니다.

로컬 검증 페이지는 /__qa__/handling-review.html이며 공개 배포에 포함하지 않습니다. 하네스의 접지 회복 재현은 검증용 입력을 사용하고 실제 플레이에 자동 조향을 넣지 않습니다.

## 현재 게임

차고에서 차량을 고르고 경주를 완주하면 순위에 따라 상금을 받습니다. 상금으로 도색·휠·엔진·타이어·브레이크를 구매하고 다음 경주에 도전합니다. 가속·브레이크·후진은 각각 별도 버튼이며 드리프트는 선택해서 사용합니다. 차 뒤 시점과 운전석 시점을 지원합니다.

Tavaculo 운전석에는 별도 공간 시안에서 확인한 Gallardo 원본 실내를 적용했습니다. 낮은 왼쪽 눈 위치와 원본 앞유리·A필러·대시보드·핸들의 비율을 유지하며, 실제 주행 물리에서 계산한 조향에 따라 원본 핸들이 돌아갑니다. 시선은 같은 방향으로 최대 6° 따라갔다가 정면으로 돌아옵니다. 차고나 일시정지 메뉴에서 **조향 따라 시선 이동**을 끌 수 있으며, 이 선택은 현재 열린 탭에서만 유지됩니다. 상금·꾸미기 기록의 저장 형식은 바꾸지 않았습니다.

원본 계기판 앞에는 실제 속도와 전후진 상태를 보여 주는 작은 화면을 더했습니다. 화면은 최대 초당 10회 갱신하며 단수와 엔진 회전수는 속도에 맞춘 게임용 표시입니다. 룸미러는 뒤쪽 도시와 차량을 실제로 비춥니다. 세로 화면에서는 실내를 변형하지 않고 같은 후방 영상을 화면 위쪽에 따로 표시합니다. 가로에서는 실내 계기, 세로에서는 보조 속도 표시로 주행 상태를 확인합니다. F2002는 기존의 중앙 운전석을 유지합니다. 원본 실내의 공간감을 도시 주행에 연결한 구성이며 실차 치수·엔진·변속기의 정밀 재현을 뜻하지 않습니다.

스마트폰은 가로 화면을 권장합니다. 왼손으로 좌우 방향을, 오른손으로 가속·제동·후진·드리프트를 조작합니다. 컴퓨터는 방향키/WASD, Space(제동), X(후진), Shift(드리프트), C(시점), P/Esc(일시정지), R(도로 복귀)를 사용합니다.

진행은 같은 기기의 같은 브라우저에 저장됩니다. 주소가 다른 게임 사이에는 **저장 기록 옮기기**에서 파일로 이전합니다. 자동 동기화 기능은 아닙니다.

## 기존 기록 이전

1. 기록이 있는 스마트폰·브라우저에서 [기존 Sites 게임](https://hojin-city-gp.wishbridge7.chatgpt.site/?v=save-transfer-1)을 열고 **저장 기록 옮기기 → 현재 기록 파일 내려받기**로 JSON 파일을 보관합니다.
2. [GitHub 게임](https://wishjosh.github.io/dream-garage/?v=save-transfer-1)의 **저장 기록 옮기기**에서 그 파일을 선택합니다.
3. 현재 기록과 파일의 상금·보유품·두 차량의 장착 상태·최고 기록·완주 횟수·설정을 비교한 뒤 **이 기록으로 바꾸기**를 누릅니다.

불러오기는 두 기록을 합산하지 않고 파일의 기록으로 교체합니다. 선택·미리보기·취소만으로 기록을 바꾸지 않습니다. 적용 전에 현재 기록을 자동 백업하며, **가져오기 전 기록 확인 → 이전 기록으로 되돌리기**에서 확인 후 복원할 수 있습니다. 중요한 기록은 파일로도 따로 보관하세요. 백업이나 저장을 확인하지 못하면 성공 처리하지 않습니다.

파일 처리는 해당 브라우저 안에서 진행하며 개인 저장 파일을 GitHub나 서버로 업로드하지 않습니다. 기존 주소의 기록은 내보내기로 삭제되지 않습니다. 이전 후에는 새 GitHub 주소를 사용하면 진행이 갈라지는 것을 줄일 수 있습니다. 앱 식별자·형식·값·크기를 확인해 다른 게임이나 손상된 파일을 거절합니다. 브라우저의 사이트 데이터를 지우면 그 주소의 저장과 자동 백업이 함께 사라질 수 있습니다.

## 개발과 게시

이 저장소를 앞으로의 GitHub 개발 기준으로 사용합니다. 최초 게임 파일은 기존 Sites 버전 11의 소스 커밋 `99ec629e11176e6e0a6fa4b974e7f19ae4ae6ebd`와 같습니다. 이전 변경 이력과 내부 제작 기록은 기존 로컬 저장소에 보존하고 공개 저장소는 이 검증본부터 시작합니다.

Node.js 22 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm run dev
npm run check
npm test
```

개발 주소는 `http://127.0.0.1:4177/`이며 운전석 검토 화면은 `/__qa__/cockpit-review.html`, 저장 이전 검토 화면은 `/__qa__/save-review.html`입니다. `dist/`에 게임 소스와 실행 자료, `tests/`에 105개 검사, `scripts/`에 개발 서버와 로컬 검토 도구가 있습니다.

`main`에 코드를 올리거나 pull request를 만들면 GitHub Actions가 JavaScript와 자동 검사를 실행합니다. 공개 게임 갱신은 **Check and publish game → Run workflow → main**을 수동 실행합니다. 검사가 통과한 뒤 `dist/`만 GitHub Pages에 게시합니다. 코드 업로드만으로 플레이 화면이 바뀌지 않습니다. 기존 Sites 주소와 자동 동기화하지 않습니다.

기본 검사는 물리 주행·전후진·드리프트·상금·구매·저장·바퀴·후방 카메라를 확인합니다. 로컬 운전석 검토는 합성 입력과 화면 크기 재현을 사용하며 실제 휴대폰의 멀티터치 하드웨어·성능·조작감을 대신하지 않습니다.

**본 게임 원본 운전석 통합 검증 — 2026-10-22:** 자동 검사 86개와 두 차량 × 6개 화면 크기(844×390·740×360·390×844·360×740·320×568·568×320)의 12개 시나리오가 통과했습니다. 원본 비례·고정 눈 위치, 실제 조향과 시선 복귀·설정, 가감속·후진·드리프트, 입력 해제·화면 회전·시점 전환, 계기·후방 영상과 UI 가림을 검사했습니다. 별도 경주 완주에서는 자동 조향 중 정면 시선 유지, 순위 상금 1회 지급, 차고 반영과 기존 꾸미기·저장 형식 보존을 확인했습니다. 실제 브라우저의 가속·조향 버튼 길게 누르기와 렌더 화면을 확인했으며 실행 오류는 없었습니다. 모델 로딩 중 가로→세로로 회전했을 때 렌더 크기가 이전 화면에 남는 문제를 수정했으며, 로딩을 지연한 재현 검사에서 추가 회전 없이 캔버스·카메라 비율과 원본 운전석 출발이 정상임을 확인했습니다. 합성 터치와 PC 브라우저 화면 크기 재현이므로 실제 iPhone·Android의 장시간 성능과 두 엄지 조작감은 검증 전입니다.

## 원본 실내 공간 시안

[이전 화면과 비교](https://wishjosh.github.io/dream-garage/cockpit-comparison.html) · [실내에서 직접 둘러보기](https://wishjosh.github.io/dream-garage/cockpit-study.html?view=clean)

본 게임에 적용한 Gallardo 원본의 44개 실내·차체 부품을 따로 살펴보는 공간 시안입니다. 모든 부품에 같은 배율과 축 변환을 적용하고, 화면 크기에 따라 핸들이나 필러를 개별 변형하지 않습니다. 왼쪽 좌석의 눈높이·앞뒤 위치, 시선의 기울기와 시야각을 조절할 수 있습니다. 기본값은 수직 42.39°(844×390에서 수평 80°), 아래로 4°의 시선입니다. 원본 좌석에 맞춰 정한 검토값이며 실차 측정값은 아닙니다.

왼쪽 아래의 좌우 버튼을 누르고 있거나 A/D·방향키를 누르면 원본 핸들이 돌아가고 시선이 같은 방향으로 최대 6° 따라갑니다. 손을 떼면 부드럽게 정면으로 돌아오며, **시선 따라가기**를 끄면 핸들만 회전합니다. 눈 위치·화면 기울기·시야각은 조향 때문에 달라지지 않습니다. 원본 핸들의 중심과 기울어진 축으로 핸들 하나만 회전하고, 뒤쪽 레버와 컬럼 덮개는 고정합니다. 화면 회전·창 전환·입력 취소 때 남은 입력을 해제합니다. 이번 조향은 공간 시안의 핸들·시선 비교이며 직선 재생 경로를 바꾸지는 않습니다.

재질은 공간 형태를 보기 위한 중립색입니다. 작은 스위치·좌석 밑부분의 면 수를 줄인 GLB는 4.15MB, 202,182삼각형입니다. 별도 공간 시안의 가속·제동은 11초 동안 56m를 이동하는 정해진 재생입니다. 도시에서 직접 운전하려면 본 게임을 사용합니다. 본 게임에서는 같은 원본 실내를 주행 물리에 연결하고 실시간 룸미러와 작동 계기를 추가했습니다. 원본은 미완성 모델이며, 기존 Tavaculo/F2002 주행과 상금·저장 기능은 유지됩니다.

`/__qa__/study-review.html`이 로컬 검토 도구입니다. 실제 모델로 좌석·시선·시야 변경, 844×390·568×320·390×844·320×568 크기, 0/4/7/11초 이동, 조향·시선 복귀·입력 취소·시선 연동 끄기와 버튼 배치의 48개 검사를 실행합니다. 원본 비례 검사는 아래 명령으로 실제 GLB 좌표와 변환 보고서를 대조합니다.
